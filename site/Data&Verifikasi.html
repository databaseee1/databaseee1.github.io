Data & Verifikasi

Keamanan Data Pengguna

Informasi akun dan proses verifikasi digunakan untuk menjaga keamanan transaksi.

1. Data Akun

  • Pastikan email dan nomor WhatsApp aktif.
  • Jangan memberikan password kepada siapapun.
  • Gunakan data yang benar untuk menghindari masalah akun.
Data tersimpan dengan aman.

2. Proses Verifikasi

1

Pengguna mengisi data akun dengan benar.

2

Sistem melakukan pengecekan informasi.

3

Akun dapat digunakan untuk melakukan transaksi.

3. Perlindungan Akun

Kami tidak meminta password pengguna melalui chat atau pihak lain. Selalu periksa informasi sebelum melakukan tindakan.

Jika menemukan aktivitas mencurigakan, segera hubungi customer service.

4. Perubahan Data

Pengguna dapat memperbarui data profil melalui menu edit profil. Perubahan tertentu mungkin membutuhkan pengecekan ulang.
